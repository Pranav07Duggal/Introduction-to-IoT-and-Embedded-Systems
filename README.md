# Introduction to IoT and Embedded Systems – Assignment Repository

This repository contains coursework, assignments, and project work submitted as part of the **Introduction to IoT and Embedded Systems** course. The course covers fundamental concepts in the design and implementation of Internet of Things (IoT) applications, embedded hardware/software, and real-world device integration.

## Topics Covered

- Overview of IoT and embedded systems
- Microcontrollers vs. microprocessors
- Sensors and actuators
- Communication protocols (I2C, SPI, UART)
- Internet protocols (TCP/IP, HTTP, MQTT)
- Embedded programming using Arduino and Raspberry Pi
- Data acquisition and processing
- Introduction to RTOS (Real-Time Operating Systems)
- Security and privacy concerns in IoT

## Tools and Platforms

- **Arduino IDE**
- **Raspberry Pi OS / Raspbian**
- **Python**
- **C/C++ for Embedded Systems**
- **Wireshark (for network analysis)**
- **MQTT Broker (e.g., Mosquitto)**
